## Sobre o Projeto

Repositório oficial da equipe **Relaxed Runtime** para o **Hackathon SouJunior**. 

Este projeto é uma Landing Page *mobile-first* de página única, focada em conversão, storytelling e transparência. O objetivo é engajar a comunidade e captar apoiadores recorrentes para a campanha oficial da SouJunior no Apoia.se, garantindo a sustentabilidade da oferta de mentorias gratuitas e projetos open-source para profissionais em início de carreira.

## Stack Tecnológica e Funcionalidades

A aplicação foi construída adotando uma abordagem simplificada, visando máxima performance e baixo tempo de carregamento:

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**

**Principais Features implementadas:**
- [x] Navegação fluida por âncoras via CSS nativo.
- [x] Cards informativos de faixas de apoio a partir de R$ 2,00.
- [x] Componente *Accordion* nativo em HTML para FAQ.
- [x] Animação progressiva dos contadores de impacto ao rolar a página.
- [x] Redirecionamento seguro (`target="_blank" rel="noreferrer"`) para o ecossistema SouJunior e checkout no Apoia.se.
- [x] Layout adaptativo para desktop e dispositivos móveis.

## Estrutura do Projeto

O repositório adota uma organização direta na raiz para facilitar a visualização e execução imediata:

    SouJunior/
    ├── img/                       # Diretório contendo os assets visuais exportados
    │   └── SouJunior, início.svg  # Logo da marca utilizado na navegação

## Como Executar Localmente

Por se tratar de um projeto estático, não há necessidade de instalação de dependências ou *build steps* complexos.

1. Clone este repositório para a sua máquina local;
2. Acesse a pasta do projeto:
       cd SouJunior
3. Abra o arquivo `index.html` diretamente em qualquer navegador moderno para visualizar a aplicação.
